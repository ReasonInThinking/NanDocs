# 🗂️ NanDocs

Быстрый и минималистичный док-менеджер избранных файлов, директорий и программ для **Linux (x86_64)**, написанный на Flutter. ⚡

> 🆕 **Обновление v1.1.0:** Теперь в **NanDocs** можно добавлять любые установленные на компьютере программы! Выбирайте приложения из встроенного списка с поиском или просто перетаскивайте `.desktop`-ярлыки в окно.

## ✨ Возможности
- 🧩 **Каталог программ и `.desktop`-ярлыки:** добавляйте любые установленные в системе приложения (APT, Flatpak, Snap) через кнопку «Программа» или перетаскиванием `.desktop`-файлов.
- 🖱️ **Drag & Drop:** перетаскивайте любые файлы, директории и `.AppImage` прямо в окно приложения.
- 📁 **Умные категории:** создавайте собственные вкладки для программ, проектов, документов и медиа.
- 🚀 **Запуск в один клик:** открывайте документы штатными средствами или запускайте программы напрямую.
- 🔗 **Без дублирования данных:** приложение хранит только пути к оригиналам в `~/.file_dock.json` и не занимает лишнее место на диске.

## 📦 Быстрая установка (Linux x86_64)

Приложение распространяется в формате автономного **AppImage** и подходит для любых 64-битных дистрибутивов Linux на процессорах Intel/AMD (Ubuntu, Zorin OS, Linux Mint, Debian, Fedora, Arch и др.).

### 1. Скачивание файлов ⬇️
1. Перейдите во вкладку **[Releases](../../releases)** справа и скачайте свежий файл **`NanDocs-x86_64.AppImage`**.
2. Также сохраните файл **`logo.png`** из корня этого репозитория, если хотите добавить программу в меню приложений со штатной иконкой.
3. Создайте удобную директорию и поместите туда оба файла.

### 2. Права на запуск 🔑
Откройте терминал в директории с файлами и разрешите выполнение:
```bash
chmod +x NanDocs-x86_64.AppImage
```

### 3. Добавление в меню приложений Linux (Zorin OS, Ubuntu, Mint) 🖥️
Просто скопируйте и выполните эту команду в терминале — она сама найдёт скачанный файл в вашей домашней папке и создаст ярлык в меню:

```
APP_PATH=$(find "$HOME" -maxdepth 4 -name "NanDocs-x86_64.AppImage" 2>/dev/null | head -n 1)
APP_DIR=$(dirname "$APP_PATH")
chmod +x "$APP_PATH"

cat << EOF > ~/.local/share/applications/nandocs.desktop
[Desktop Entry]
Type=Application
Name=NanDocs
Comment=Быстрый док для избранных файлов и программ
Exec=env GDK_BACKEND=x11 $APP_PATH
Icon=$APP_DIR/logo.png
Categories=Utility;FileManager;
Terminal=false
StartupWMClass=NanDocs
EOF

update-desktop-database ~/.local/share/applications/
```
